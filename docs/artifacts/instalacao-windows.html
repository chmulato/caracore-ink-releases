Instalação Windows — Ink Agenda v2.0.0

Windows 10 / 11 · 64 bits · setup ou ZIP portátil · Java 25 embutido (sem JDK)

Requisitos

  • Windows 10 ou 11 (64 bits)
  • Cerca de 200 MB livres em disco
  • Sem JDK: o runtime Java 25 vem no pacote
  • Internet só para baixar. Depois o app funciona offline
  • ZIP portátil não exige administrador. O setup pode pedir confirmação do Windows

Instalar com o setup (.exe)

  1. Baixe AgendaInk-2.0.0-windows-setup.exe.
  2. Opcional: confira o SHA256 com o checksum.sha256 da tag v2.0.0.
  3. Execute o instalador e siga o assistente.
  4. Abra o Ink Agenda pelo atalho ou por AgendaInk.exe.

Usar o ZIP (portable)

  1. Baixe AgendaInk-2.0.0-windows.zip.
  2. Opcional: confira o SHA256.
  3. Clique direito → Extrair aqui.
  4. Abra a pasta AgendaInk\ e execute AgendaInk.exe.

Onde ficam os dados

Na primeira execução o banco é criado em:

%LOCALAPPDATA%\CaraCore\AgendaInk\agenda.db

Reinstalar o setup ou apagar a pasta do ZIP não apaga essa pasta. É o mesmo arquivo se você voltar a abrir o app neste Windows.

Aviso de antivírus / SmartScreen

O pacote Windows desta tag não traz assinatura de código comercial. O SmartScreen ou o antivírus pode avisar ao abrir AgendaInk.exe ou o setup. Isso é esperado em software sem assinatura.

  • No SmartScreen: Mais informações → Executar mesmo assim.
  • Só execute depois de conferir o SHA256 oficial.

Primeiro acesso (login)

O build v2.0.0 não traz usuário pronto. Não existe login admin. Isto não é o PDV Cara Core (nem admin/admin do Java, nem admin/admin123 do Rust).

Não é e-mail. Não é conta Cara Core na nuvem. Tudo fica neste computador (SQLite).

O que a primeira abertura mostra

  1. Abra AgendaInk.exe (Java 25 já vem no pacote).
  2. Aparece a tela de login com o aviso Primeiro acesso (assistido): “Informe o celular do responsável e clique em Continuar para primeiro acesso.”
  3. O campo de senha ainda não aparece. Só o celular (exemplo de máscara: (11) 99999-9999).
  4. O botão é Continuar para primeiro acesso.
  5. Na tela seguinte, confirme o celular. O app avisa: “Tudo ocorre neste dispositivo: nenhuma conta externa é necessária.”
  6. Na tela de configuração, escolha o perfil inicial (Proprietário, Tatuador Sr ou Tatuador Jr), defina a senha (mínimo 8 caracteres, com confirmação) e a frase de recuperação (mínimo 10 caracteres, com confirmação). Opcional: gerar códigos de emergência (anote — o app mostra uma vez).
  7. O app volta à tela de login. Aí sim: celular + senha e Entrar com celular.

Já existe usuário neste Windows

Se agenda.db já tiver credencial, a tela pede celular e senha de imediato (botão Entrar com celular). Pode marcar “Lembrar da minha senha” neste dispositivo (até 12 horas ou até sair). Após 5 tentativas erradas o acesso bloqueia cerca de 10 minutos.

Esqueci a senha

Não há recuperação por SMS, e-mail ou internet. No login, Esqueci a minha senha gera um código de 6 dígitos só nesta tela, neste computador (cerca de 15 minutos). Exige a frase de recuperação definida no primeiro acesso. Se você gerou códigos de emergência, um deles também serve (uso único). Sem a frase (e sem código de emergência), o caminho honesto é restaurar um backup local ou começar de novo apagando a pasta de dados — isso apaga a agenda deste PC.

Depois de entrar

  • 1 cliente
  • 1 agendamento
  • 1 receita ou despesa
  • 1 backup manual (exportação na linha 2.0.0)

Desinstalação

Setup: use Aplicativos do Windows para remover o programa. ZIP: apague a pasta extraída. Os dados em %LOCALAPPDATA%\CaraCore\AgendaInk\ só saem se você apagar essa pasta.
