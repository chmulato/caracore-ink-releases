Instalação Windows — Cara Core Ink Agenda

Windows 10 / 11 · 64 bits · setup ou ZIP portátil · Java 25 embutido (sem JDK)

Os executáveis não têm assinatura digital. O SmartScreen ou antivírus pode avisar ou bloquear; faça backup dos dados antes de atualizar. Não há promessa de instalação sem alertas.

Requisitos

  • Windows 10 ou 11 (64 bits)
  • Cerca de 200 MB livres em disco
  • Sem JDK: o runtime Java 25 vem no pacote
  • Internet só para baixar. Depois o app funciona offline: não abre porta nem faz conexão
  • ZIP portátil não exige administrador. O setup pode pedir confirmação do Windows

Instalar com o setup (.exe)

  1. Baixe AgendaInk-2.0.3-windows-setup.exe.
  2. Confira o SHA256 com o checksum.sha256 da versão baixada.
  3. Execute o instalador e siga o assistente. Faça backup dos dados antes de testar.
  4. Abra o Ink Agenda pelo atalho ou por AgendaInk.exe.

Usar o ZIP (portable)

  1. Baixe AgendaInk-2.0.3-windows.zip.
  2. Opcional: confira o SHA256.
  3. Clique direito → Extrair aqui.
  4. Abra a pasta AgendaInk\ extraída e execute AgendaInk.exe.

Onde ficam os dados

Na primeira execução o banco é criado em:

%LOCALAPPDATA%\CaraCore\AgendaInk\agenda.db

Reinstalar o setup ou apagar a pasta do ZIP não apaga essa pasta. A atualização preserva a agenda existente e não perde dados; faça backup antes de atualizar.

Na mesma pasta ficam a subpasta backups\ (backup automático) e a subpasta logs\ (registro técnico, sem senha, telefone ou e-mail; 5 arquivos de até 1 MB, o mais antigo é apagado).

Aviso de antivírus / SmartScreen

Os executáveis não têm assinatura digital. O SmartScreen ou o antivírus pode avisar ou bloquear ao abrir AgendaInk.exe ou o setup. Não há promessa de instalação sem alertas.

  • No SmartScreen: Mais informações → Executar mesmo assim.
  • Só execute depois de conferir o SHA256 oficial.

Primeiro acesso

O Ink Agenda não traz usuário pronto. Não existe login admin. Isto não é o PDV Cara Core (nem admin/admin do Java, nem admin/admin123 do Rust).

Não é e-mail. Não é conta Cara Core na nuvem. Tudo fica neste computador.

O que a primeira abertura mostra

  1. Abra AgendaInk.exe (Java 25 já vem no pacote). Um aviso abre junto com a janela: “Seus dados ficam só neste computador. O Ink Agenda está pronto para uso.” Clique em OK.
  2. A primeira tela é Passo 1 de 3 — Identificação (“Bem-vindo ao Ink Agenda”). Informe o celular do responsável (máscara (11) 99999-9999) e clique em Continuar.
  3. Passo 2 de 3 — Senha e recuperação local: escolha o perfil inicial (Proprietário, Tatuador Sr ou Tatuador Jr), defina a senha (mínimo 8 caracteres, com confirmação) e a frase de recuperação (mínimo 10 caracteres, com confirmação). Recomendado: gerar os 8 códigos de emergência (anote — o app mostra uma vez). Clique em Concluir configuração.
  4. Passo 3: a tela de login aparece só agora. Entre com o mesmo celular e a senha que acabou de criar.

Já existe usuário neste Windows

Se agenda.db já tiver credencial, a primeira tela é o login (celular e senha). Pode marcar “Lembrar da minha senha” neste dispositivo (até 12 horas ou até sair). Quem usava essa opção em uma versão anterior digita a senha mais uma vez. Após 5 tentativas erradas o acesso bloqueia cerca de 10 minutos.

Esqueci minha senha

Não há recuperação por SMS, e-mail ou internet. No login, Esqueci minha senha gera um código de 6 dígitos só nesta tela, neste computador (válido por 15 minutos). Exige a frase de recuperação definida no primeiro acesso. Se você gerou códigos de emergência, um deles também serve (uso único). Sem a frase (e sem código de emergência), o caminho honesto é restaurar um backup ou começar de novo apagando a pasta de dados — isso apaga a agenda deste PC.

Depois de entrar

  • 1 cliente (aba Clientes)
  • 1 agendamento com horário, duração e valor
  • 1 receita ou despesa
  • 1 backup com senha (Config → Backup do estúdio)

Backup

Backup com senha (.inkbak)

Em Config → Backup do estúdio → Salvar backup com senha você escolhe a pasta e o nome do arquivo (sugestão: backup_AAAA-MM-DD_HH-MM.inkbak em Documentos\AgendaInk\Backups). Se já existir um arquivo com o mesmo nome, o app grava ao lado com “(2)”, “(3)”… — nunca sobrescreve. O arquivo é criptografado com a senha que você digitar (mínimo 8 caracteres). Sem essa senha o backup não abre. Ao terminar, o app mostra o caminho onde salvou.

Para restaurar: Restaurar backup, escolha o arquivo e digite a senha. Backups .inkbak da v2.0.0 (sem senha) também restauram. O app confere o arquivo antes de trocar os dados e fecha ao terminar; abra de novo para continuar.

Backup automático

Ligado de fábrica: a cada hora e ao fechar o app, uma cópia agenda_AAAA-MM-DD_HH-MM-SS.db.gz vai para %LOCALAPPDATA%\CaraCore\AgendaInk\backups\. O app guarda as 30 mais recentes e apaga as mais antigas. Essas cópias ficam neste computador e não têm senha. Para desligar ou religar, desmarque ou marque “Fazer backup automático a cada hora e ao fechar” em Config → Backup do estúdio.

Backup CSV

Em Config há também a exportação CSV compactada e criptografada com senha. O CSV leva agendamentos (com valor e duração) e os lançamentos do Financeiro; clientes, orçamentos, cobranças e recebimentos ficam só no backup .inkbak. Importar o mesmo arquivo duas vezes não duplica nada; horários em conflito viram aviso e lista de ignorados.

Desinstalação

Setup: use Aplicativos do Windows para remover o programa. ZIP: apague a pasta extraída. Os dados em %LOCALAPPDATA%\CaraCore\AgendaInk\ só saem se você apagar essa pasta.
