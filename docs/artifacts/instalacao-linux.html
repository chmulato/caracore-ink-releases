Instalação Linux — CaraCore Ink Agenda

Ubuntu / Debian · 64 bits · pacote .deb com runtime Java 25 embutido (sem JDK)

O pacote não tem assinatura digital. Faça backup dos dados antes de atualizar. O app não abre porta e não faz conexão em segundo plano: funciona offline. A única conexão é a verificação manual de atualizações, que envia apenas a versão do app e o sistema operacional.

Download (versão v2.1.0)

Arquivo oficial da release v2.1.0. Valide com o checksum-linux-2.1.0.txt da release (o checksum.sha256 cobre os arquivos do Windows).

↓ agenda-ink-2.1.0-linux.deb

SHA256 DEB 58c0d3f0024c9b4ef06fd727283439490325a6dca053a5d93e000169f870bf18

Instalar o pacote

  1. Baixe agenda-ink-2.1.0-linux.deb.
  2. Confira o SHA256 com o arquivo oficial da release.
  3. No terminal, na pasta do download: sudo apt install ./agenda-ink-2.1.0-linux.deb.
  4. Abra o Ink Agenda pelo menu de aplicativos.

O apt resolve as dependências do sistema; o runtime Java 25 já vai no pacote.

Onde ficam os dados

No Linux, o banco e os arquivos locais ficam em ~/.caracore-ink/ (banco agenda.db, backup automático em backups/ e registro técnico em logs/). Reinstalar o pacote não apaga essa pasta. Faça backup antes de atualizar.

Primeiro acesso

O Ink Agenda não traz usuário de fábrica. Na primeira abertura, escolha o perfil do espaço — Tatuagem, Odontologia ou Beleza —, informe o celular do responsável e conclua a senha e a recuperação local. Guia completo em Primeiro acesso.

Linux na linha 3.0

O Desktop v2.1.0 é o canal atual para Linux. A linha 3.0 atenderá pelo navegador, não antes de 2028; a página do roadmap é PWA.
