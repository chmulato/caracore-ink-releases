Instalação padrão no Windows 10/11

  1. Baixe AgendaInk-2.0.1-windows-setup.exe ou o ZIP AgendaInk-2.0.1-windows.zip.
  2. Opcionalmente, valide o hash com o checksum.sha256 da release v2.0.1 (ou com os SHA256 desta página).
  3. Execute o instalador, ou descompacte o ZIP portátil e abra AgendaInk.exe.

Como usar o ZIP Windows (modo portable)

  1. Baixe e salve AgendaInk-2.0.1-windows.zip.
  2. Descompacte (clique direito → Extrair aqui).
  3. Abra a pasta AgendaInk\.
  4. Execute AgendaInk.exe com duplo clique.
  5. Na primeira execução o banco de dados será criado em:
    %LOCALAPPDATA%\CaraCore\AgendaInk\agenda.db

Na primeira abertura o app vai direto ao Passo 1 de 3 — Identificação (celular do responsável). O login só aparece depois de criar a senha. Não é o PDV. Primeiro acesso · mesma seção no guia Windows.
