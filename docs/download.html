Windows 10/11 · 64 bits · sem instalar Java.

↓ Instalador (recomendado) ↓ ZIP portátil

Versão 2.0.2.

Como começar

  1. Baixe o instalador (recomendado) ou o ZIP portátil.
  2. Execute o setup, ou extraia o ZIP, abra a pasta AgendaInk\ e execute AgendaInk.exe.
  3. Conclua o primeiro acesso em 3 passos.

Os dados ficam em %LOCALAPPDATA%\CaraCore\AgendaInk\. Quem usa a v2.0.0 mantém a mesma agenda.

O executável ainda não tem assinatura de código. O SmartScreen ou o antivírus pode avisar ou bloquear a abertura; veja as orientações para Windows. Não há promessa de instalação sem alertas.

Verificar integridade (opcional)

(Get-FileHash .\AgendaInk-2.0.2-windows-setup.exe -Algorithm SHA256).Hash
(Get-FileHash .\AgendaInk-2.0.2-windows.zip -Algorithm SHA256).Hash
