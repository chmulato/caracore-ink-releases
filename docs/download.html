Versão 2.1.0 · Windows 10/11 e Linux · sem assinatura digital.

Antes de atualizar

Os executáveis não têm assinatura digital, e o SmartScreen ou antivírus pode avisar ou bloquear a abertura. Faça backup dos dados antes de atualizar: bases das versões 2.0.1 a 2.0.4 abrem na 2.1.0 sem perda. Na primeira abertura da 2.1.0, o operador escolhe o perfil do negócio — Tatuagem, Odontologia ou Beleza — e pode trocar depois sem reinstalar.

O que mudou em cada versão publicada está em Versões, com data e links das notas oficiais.

Como começar

  1. Baixe o instalador (recomendado) ou o ZIP portátil.
  2. Execute o setup, ou extraia o ZIP e execute AgendaInk.exe.
  3. Conclua o primeiro acesso em 3 passos.

Os dados ficam em %LOCALAPPDATA%\CaraCore\AgendaInk\. Quem usa uma versão 2.0.1 a 2.0.4 mantém a mesma agenda e escolhe o perfil na abertura.

O setup e o executável Windows não têm assinatura digital. O SmartScreen ou o antivírus pode avisar ou bloquear a abertura. Veja as orientações para Windows; não há promessa de instalação sem alertas.

Verificar integridade (opcional)

Compare os arquivos baixados com os SHA-256 publicados na release:

setup.exe · 81fd338fdc3ae8dbcb406ced7bcbb9a54fb05a447c28d999c6c5482a1aed4dbd

windows.zip · 4e8b66667d875561ba6ee67295724a15c70051928256423a316f8e89055e2551

No PowerShell, na pasta onde os arquivos foram salvos:

(Get-FileHash .\AgendaInk-2.1.0-windows-setup.exe -Algorithm SHA256).Hash
(Get-FileHash .\AgendaInk-2.1.0-windows.zip -Algorithm SHA256).Hash

Arquivos oficiais: checksum.sha256 desta versão · release v2.1.0 · versões anteriores.

Outros sistemas: Linux (.deb) · SHA-256 58c0d3f0024c9b4ef06fd727283439490325a6dca053a5d93e000169f870bf18 | macOS: sem suporte nesta versão; a linha 3.0 atenderá pelo navegador no roadmap

Pronto para usar · Não exige instalação de Java. No Linux, instale com sudo apt install ./agenda-ink-2.1.0-linux.deb. Na primeira abertura, o sistema pode pedir confirmação por o aplicativo ainda não ter assinatura digital.
