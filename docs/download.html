Como começar

  1. Baixe o instalador (recomendado) ou o ZIP portátil no Windows; no Linux, baixe o .deb.
  2. Execute o setup, extraia o ZIP e abra AgendaInk.exe, ou instale o .deb.
  3. Conclua o primeiro acesso em 3 passos: perfil, celular e senha.

No Windows, os dados ficam em %LOCALAPPDATA%\CaraCore\AgendaInk\agenda.db, fora da pasta do ZIP ou do setup. Quem usa uma versão 2.0.1 a 2.0.4 mantém a mesma agenda e escolhe o perfil na abertura.

No Linux, instale com sudo apt install ./agenda-ink-2.2.1-linux.deb.

Verificar integridade (opcional)

Compare os arquivos baixados com os SHA-256 publicados acima e com o arquivo oficial da release.

No Windows PowerShell, na pasta onde os arquivos foram salvos:

(Get-FileHash .\AgendaInk-2.2.1-windows-setup.exe -Algorithm SHA256).Hash
(Get-FileHash .\AgendaInk-2.2.1-windows.zip -Algorithm SHA256).Hash

No Linux, na pasta do .deb:

sha256sum agenda-ink-2.2.1-linux.deb

Arquivos oficiais: checksum.sha256 (Windows) · checksum-linux-2.2.1.txt (Linux) · release v2.2.1.

Requisitos e avisos

  • Windows: Windows 10/11 de 64 bits. Não é preciso instalar JDK: o runtime Java 25 vai no pacote.
  • Linux: sistema de 64 bits com suporte a pacotes .deb.
  • Assinatura digital: não há. O SmartScreen ou o antivírus pode avisar; veja as orientações para Windows. Não há promessa de instalação sem alertas.
  • Dados locais: agenda, clientes, orçamentos e finanças ficam no computador. O backup .inkbak é criptografado com senha. Como protegemos os dados.

Assinatura e ativação

R$ 79,90/mês por instalação. Inclui o uso do Ink Agenda, o suporte da Cara Core, as correções de bug e as novas versões.
