Versão 2.0.4 · Windows 10/11 · sem assinatura digital.

Antes de atualizar

Os executáveis não têm assinatura digital, e o SmartScreen ou antivírus pode avisar ou bloquear a abertura. Faça backup dos dados antes de atualizar: agendas das versões 2.0.x abrem na versão atual sem perda.

O que mudou em cada versão publicada está em Versões, com data e links das notas oficiais.

Como começar

  1. Baixe o instalador (recomendado) ou o ZIP portátil.
  2. Execute o setup, ou extraia o ZIP e execute AgendaInk.exe.
  3. Conclua o primeiro acesso em 3 passos.

Os dados ficam em %LOCALAPPDATA%\CaraCore\AgendaInk\. Quem usa a v2.0.0 mantém a mesma agenda.

O setup e o executável Windows não têm assinatura digital. O SmartScreen ou o antivírus pode avisar ou bloquear a abertura. Veja as orientações para Windows; não há promessa de instalação sem alertas.

Verificar integridade (opcional)

Compare os arquivos baixados com os SHA-256 publicados na release:

setup.exe · 5ea79dac30719ef11150e2f5de09d340b697f967918524ae12761c07051ebd1c

windows.zip · 7849d462625dbb356900d6e7f97a54c491d634ad5ac9b7cee9a6c8f3ee3e6fd3

No PowerShell, na pasta onde os arquivos foram salvos:

(Get-FileHash .\AgendaInk-2.0.4-windows-setup.exe -Algorithm SHA256).Hash
(Get-FileHash .\AgendaInk-2.0.4-windows.zip -Algorithm SHA256).Hash

Arquivos oficiais: checksum.sha256 desta versão · release v2.0.4 · versões anteriores.

Outros sistemas: Linux (.deb) | macOS: sem suporte nesta versão; a linha 3.0 atenderá pelo navegador no roadmap

Pronto para usar · Não exige instalação de Java. No Linux, instale com sudo apt install ./agenda-ink-2.0.4-linux.deb. Na primeira abertura, o sistema pode pedir confirmação por o aplicativo ainda não ter assinatura digital.
