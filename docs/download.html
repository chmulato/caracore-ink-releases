Windows 10/11 · 64 bits · sem instalar Java.

↓ Instalador (recomendado) ↓ ZIP portátil

Versão 2.0.1.

Como começar

  1. Baixe o instalador (recomendado) ou o ZIP portátil.
  2. Execute o setup, ou extraia o ZIP e abra a pasta AgendaInk\.
  3. Abra o AgendaInk.exe e conclua o primeiro acesso em 3 passos.

Os dados ficam em %LOCALAPPDATA%\CaraCore\AgendaInk\. Quem usa a v2.0.0 mantém a mesma agenda.

Verificar integridade (opcional)

Compare os arquivos baixados com os SHA256 oficiais da v2.0.1:

setup.exe · 49bdd76a10ab97b7902e47b8c393c638ef90ea6b490874224a9734a802f90a6b

windows.zip · 3118eac8fafdfa5cc4d3e341969d0cd205d5a29caabbe069e12d7b956a994ff3

No PowerShell, na pasta onde os arquivos foram salvos:

(Get-FileHash .\AgendaInk-2.0.1-windows-setup.exe -Algorithm SHA256).Hash
(Get-FileHash .\AgendaInk-2.0.1-windows.zip -Algorithm SHA256).Hash
