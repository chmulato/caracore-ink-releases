Instalação padrão no Windows 10/11

  1. Baixe AgendaInk-2.0.0-windows-setup.exe ou o ZIP AgendaInk-2.0.0-windows.zip.
  2. Opcionalmente, valide o hash com o checksum.sha256 da release v2.0.0 (ou com os SHA256 desta página).
  3. Execute o instalador, ou descompacte o ZIP portátil e abra AgendaInk.exe.

Como usar o ZIP Windows (modo portable)

  1. Baixe e salve AgendaInk-2.0.0-windows.zip.
  2. Descompacte (clique direito → Extrair aqui).
  3. Abra a pasta AgendaInk\.
  4. Execute AgendaInk.exe com duplo clique.
  5. Na primeira execução o banco de dados será criado em:
    %LOCALAPPDATA%\CaraCore\AgendaInk\agenda.db

Depois de abrir o AgendaInk.exe, crie o responsável no assistente de primeiro acesso (celular + senha local — não é o PDV). Primeiro acesso (login) · mesma seção no guia Windows.
