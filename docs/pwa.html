Porque o PWA amplia o mercado

O Desktop v2.0.0 cobre o computador Windows do estúdio. Não haverá linha nativa Mac ou Linux: o PWA cobre Mac, Linux, Android e tablet — mais postos de uso, sem JDK e sem jpackage nesses sistemas. É o mesmo backend da v2.

O que já está no ar

Desktop v2.0.0 para Windows (setup + ZIP, runtime Java 25 embutido). Login: celular + senha local. Dados no computador. Quem precisa do aplicativo agora usa o download Windows.

O que ainda não está no ar

Não há origem HTTPS de instalação do PWA nesta loja até 26/06/2027. Até lá o canal oficial é o Windows desktop.

Como se instala um PWA (quando o canal abrir)

No browser: Chrome ou Edge em Windows, Linux e macOS → Instalar aplicação. No Android: Chrome → Adicionar ao ecrã inicial. No iPhone: Safari → Adicionar ao ecrã inicial. Não é app da Play Store nem da App Store neste lançamento.
