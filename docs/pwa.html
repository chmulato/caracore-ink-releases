Roadmap

Ink Agenda 3.0: no browser, no celular e no computador.

O próximo passo da linha é a atualização 2.3.0 do Desktop, em 29/01/2027; a 3.0 vem depois, não antes de 2028. Web, Android, iPhone, Windows, Mac e Linux, instalada pelo browser. O macOS segue sem instalador nativo; no Linux, o Desktop v2 já publica o pacote .deb. A versão atual é o Desktop Windows e Linux v2.2.1.

Porque a 3.0 é em PWA

O Desktop v2 cobre o computador Windows e Linux do estúdio. A 3.0 abre no celular, no tablet e em qualquer computador com browser — sem JDK e sem instalador por sistema. Os agendamentos, finanças e orçamentos seguem as mesmas regras da v2.

A 3.0 substitui o Desktop

Até lá, o Desktop v2 (Windows e Linux) continua com suporte e correções. Quando a 3.0 estiver no ar, ela passa a ser o produto da loja e o Desktop v2 entra em transição. O download da v2 só sai da loja depois de existir um caminho para levar os dados do computador para a 3.0, com aviso e data publicados aqui antes.

O que já está no ar

Desktop v2.2.1 para Windows (setup + ZIP) e Linux (.deb), runtime Java 25 embutido, com três perfis: Tatuagem, Odontologia e Beleza. Login: celular + senha local. Dados no computador. Quem precisa do aplicativo agora usa o download.

O que ainda não está no ar

A 3.0 ainda não pode ser instalada. Sem data pública dura: não antes de 2028. Até lá o canal oficial é o Desktop v2 para Windows e Linux.

Onde ficam os dados na 3.0

A 3.0 vai rodar num servidor na nuvem, com HTTPS, para abrir no celular, no Mac e no browser. Cada estúdio terá a sua própria base SQLite, separada das outras. Para agendar e consultar na 3.0 é preciso internet. O Desktop v2 guarda a base no computador do estúdio; esses dados não passam sozinhos para a 3.0 — passam pela importação anunciada antes da retirada do Desktop.

Como se instala a 3.0 (quando abrir)

No browser: Chrome ou Edge em Windows, Linux e macOS → Instalar aplicação. No Android: Chrome → Adicionar ao ecrã inicial. No iPhone: Safari → Adicionar ao ecrã inicial. Não é app da Play Store nem da App Store neste lançamento.
